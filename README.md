# 每日行程管理

一個使用原生 HTML、CSS 與 JavaScript 製作的響應式每日行程管理工具，可在手機、平板與電腦瀏覽器使用。

## 功能

- 新增行程，設定日期、時間、分類、優先度與備註
- 切換完成狀態、刪除行程
- 依日期瀏覽，並檢視所有行程或完成紀錄
- 依全部、待完成、已完成篩選
- 顯示每日完成進度與摘要
- 使用瀏覽器 `localStorage` 儲存資料，不需帳號或伺服器
- 響應式版面與鍵盤／螢幕閱讀器基本支援

## 使用方式

下載或複製此專案，直接用瀏覽器開啟 `index.html` 即可。也可以部署到 GitHub Pages 等靜態網站服務。

> 行程資料只存在於目前瀏覽器的本機儲存空間，不會自動在不同裝置間同步。清除瀏覽器網站資料也會一併移除行程。

## 檔案

- `index.html`：頁面結構
- `styles.css`：視覺樣式與手機／桌面版面
- `app.js`：行程管理與本機儲存邏輯
